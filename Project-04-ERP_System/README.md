# Electronics Retail ERP System (AI-Assisted)

A professional-grade, automated Retail Management System built in Microsoft Excel, architected with the assistance of Claude AI. This system replaces expensive SaaS ERPs for small-to-medium electronics retailers.

## 📊 Key Features
- **Automated Inventory:** Real-time stock levels with FIFO (First-In-First-Out) valuation.
- **Sales & Purchase Modules:** Automatic ID generation and XLOOKUP-powered product fetching.
- **Financial Tracking:** Full tracking of Credit Sales (Receivables) and Supplier Debts (Payables).
- **Executive Dashboard:** Visual KPIs for Gross Profit, Net Profit, and Expense analysis.
- **Error Prevention:** Built-in data validation and sheet protection logic.

## 🏗️ System Architecture
The workbook follows a relational database structure:
1. **Masters:** Product, Supplier, and Customer databases.
2. **Transactions:** Daily Sales, Purchases, and Expenses entry.
3. **Analytics:** Inventory Status, P&L Statement, and Executive Dashboard.

## 🛠️ How it was Built
This system was developed using a "Consultant-Led" AI approach. I used **Claude AI** to:
- Design the relational logic between sheets.
- Debug complex nested formulas for stock calculation.
- Create the structural hierarchy for the financial reporting.

## 🚀 Getting Started
1. Download the `Electronics_ERP_System.xlsx` file.
2. Refer to the `Electronics_ERP_User_Manual.docx` for step-by-step instructions.
3. Start by entering your data in the **Masters** sheets before recording transactions.
